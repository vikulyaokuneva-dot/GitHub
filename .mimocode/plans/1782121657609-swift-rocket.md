# План: Исправления отчёта по замечаниям

## Замечания пользователя и план исправлений

### 1. Hero-таблица — формат в две колонки
**Проблема:** Карточки "залезают друг на друга", данные нечитаемы.
**Решение:** Переделать hero в таблицу с двумя колонками: Показатель | Значение.

| Показатель | Значение |
|---|---|
| Заказы | 11 шт |
| Выкупы | 6 шт |
| Сумма выкупов | 12 954,80 ₽ |
| Прибыль | 3 753,61 ₽ |
| Реклама | 192,74 ₽ |
| Остатки | 131 шт (21 дн.) |

**Файлы:**
- `report_v2/builders/report_payload_builder.py` — `_build_hero_section()`: переделать cards в rows (формат [{label, value}])
- `report_v2/renderers/pdf_renderer_v2.py` — заменить card-рендер на `_display_rows_table()`

### 2. Расхождение "Выручка от продаж" vs "Сумма выкупов"
**Проблема:** В секции "Прибыль" показана выручка 8 458 ₽ (из finance API `realized_sales_revenue`), а сумма выкупов = 12 954,80 ₽.
**Причина:** WB finance API отдаёт `realized_sales_revenue` = выручка по цене реализации (с учётом скидок/promo), а buyouts_amount из sales API = полная стоимость выкупа.
**Решение:** В секции "Прибыль" использовать `buyouts_amount` (12 954,80) как выручку, так как это то, что клиент видит в кабинете. Все затраты (комиссия, хранение, эквайринг, удержания) уже рассчитаны WB от этой суммы.

**Файлы:**
- `report_v2/builders/report_payload_builder.py` — `_build_profit_section()`: заменить `realized_sales_revenue` на `buyouts_amount` из cabinet_commerce

### 3. Unit-экономика — табличная форма
**Проблема:** Данные показаны одной строкой, нечитаемо.
**Решение:** Переделать в таблицу с колонками:

| SKU | Заказы | Выручка | Себест. | Комиссия | Реклама | Прибыль | Маржа |
|-----|--------|---------|---------|----------|---------|---------|-------|

**Файлы:**
- `report_v2/builders/report_payload_builder.py` — `_build_unit_economics_section()`: вернуть rows в формате [{label, value}] для `_display_rows_table()`
- `report_v2/renderers/pdf_renderer_v2.py` — рендерить через `_display_rows_table()`

### 4. Объединить unit-экономику и "Топ прибыльных SKU"
**Проблема:** Две одинаковые таблицы — unit-экономика и profit_contribution.
**Решение:** Удалить `unit_economics_section` из payload. Расширить `profit_contribution_section` данными unit-экономики (sebestoimost, commission, ads). Переименовать в "Товары категории А".

**Файлы:**
- `report_v2/builders/report_payload_builder.py` — удалить `_build_unit_economics_section()`, расширить profit_contribution_section
- `report_v2/renderers/pdf_renderer_v2.py` — убрать рендер unit_economics_section, оставить только profit_contribution

### 5. Порядок секций в отчёте
