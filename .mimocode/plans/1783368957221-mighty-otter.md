# Анализ логистики: Excel vs JSON API — Вариант C

## Корневая причина

Finance API **отдаёт** поля `deliveryService` и `rebillLogisticCost`, но нормализатор в `wb_api_core/normalize.py` (строки 420-440) ищет другие имена:

```python
# Текущий код (normalize.py:420-440):
logistics_amount = _parse_float_with_diag(row, (
    "deliveryRub", "delivery_rub", "deliveryCost", "delivery_cost",
    "deliveryServiceAmount", "delivery_service_amount",
    "deliveryServicesAmount", "delivery_services_amount",
    "deliveryServiceRub", "delivery_service_rub",
    "logistics_amount", "logistics", "logistics_cost",
    "Услуги по доставке товара покупателю", "Услуги доставки",
))
```

**Поле `deliveryService` НЕТ в этом списке!** WB API возвращает `deliveryService` (₽), а нормализатор его пропускает → `logistics_amount = None` → residual-расчёт.

## Подтверждение из test_finance3.py

Поле `deliveryService` содержит реальную стоимость доставки:
- 5 × 468.60₽ = 2 343₽ (кросс блок)
- 3 × 28.60₽ = 85.80₽ (трёшка)
- 2 × 208.65₽ = 417.30₽ (лошадь огненная)
- Итого: ~2 846₽ за 04.07

Поле `rebillLogisticCost` — ребиллинг логистики (корректировки WB).

## План исправления

### Шаг 1: Добавить `deliveryService` и `rebillLogisticCost` в нормализатор

Файл: `wb_api_core/normalize.py`, строки 420-440

Добавить в список имён полей:
```python
"deliveryService",           # ← WB Finance API delivery cost
"delivery_service",
"rebillLogisticCost",        # ← WB Finance API logistics rebilling
"rebill_logistic_cost",
```

### Шаг 2: Добавить `deduction` в нормализатор

WB API возвращает поле `deduction` (удержания, например WB Продвижение). Текущий код ищет `deduction` и `deductions` — проверить что поле парсится.

### Шаг 3: Обновить reconcile.py для агрегации

Добавить в `reconcile_bundle()`:
- `logistics_from_api` = SUM(deliveryService) WHERE `row_group == "logistics"`
- `logistics_rebilling` = SUM(rebillLogisticCost) WHERE `row_group == "logistics"`
- `deductions_detail` = SUM(deduction) WHERE `row_group != "sale"`

### Шаг 4: Обновить snapshot.py

Добавить в `finance_final_daily`:
- `delivery_service_total` = сумма deliveryService
- `rebill_logistic_total` = сумма rebillLogisticCost

### Шаг 5: Обновить report_payload_builder.py

В `_build_profit_section()`:
- Показать "Логистика (доставка): -X₽" вместо residual
- Показать "Ребиллинг логистики: X₽" если есть
- Показать "Удержания (WB Продвижение): -X₽"
