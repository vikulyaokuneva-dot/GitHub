# Сравнительный анализ отчётов и рекомендации по улучшению ежедневной отцифровки кабинета WB

## 1. Общее описание отчётов

| Параметр | Ежедневный отчёт (API) | Недельный аудит (файлы) |
|----------|----------------------|----------------------|
| **Источник данных** | API WB (real-time) | Скаченные отчёты WB (Excel) |
| **Период** | 1 день | 7 дней |
| **Объём** | 3 страницы | 29 страниц |
| **Фокус** | Что произошло сегодня | Почему это произошло и что делать |
| **Формат** | Сводные таблицы + топ-SKU | Аналитический документ с инсайтами |

---

## 2. Детальная структура ежедневного отчёта (API)

### Блоки отчёта:
1. **Шапка** — кабинет, дата
2. **KPI-сводка** — заказы, выкупы, сумма выкупов, прибыль, реклама, остатки
3. **Действия сегодня** — алерты (возвраты, расходы)
4. **Заказы и выкупы** — дублирование базовых метрик
5. **Детализация прибыли** — выручка, комиссия, логистика, хранение, эквайринг, возвраты, себестоимость, итого затраты, чистая прибыль, маржа
6. **Воронка продаж** — показы, клики, корзина, заказы, выкупы + конверсии между этапами
7. **Реклама** — расход, показы, клики, CTR, CPC, CPM, заказы/выручка/выкупы из рекламы, ДРР, ROAS, ROMI, CPO, прибыль от рекламы, потери, неэффективные запросы
8. **ТОП-3 SKU** — для каждого: метрики (заказы, выкупы, выручка, себестоимость, логистика, хранение, чистая прибыль, маржа, доля выручки) + мини-воронка (показы→клики→корзина→заказы→выкупы с конверсиями)

### Чего нет в ежедневном отчёте:
- ABC/XYZ-анализа ассортимента
- Рекомендаций по действиям
- Анализа поисковых запросов
- Региональной аналитики (локализация)
- Расчёта потерь (нормализованных)
- Прогнозных метрик
- Глубокого анализа логистики (переплата, ИЛ/ИРП)
- Риск-факторов по SKU
- Приоритизированного плана действий
- Сравнения с предыдущими периодами

## 3. Детальная структура недельного аудита (файлы)

### Блоки отчёта:
1. **Краткий итог по кабинету** (1 страница)
   - Потери (в ₽/мес, нормализовано)
   - Точки роста
   - Риски
   - Главный вывод
   - Прогноз: "если ничего не менять" (годовые потери)

2. **Оглавление** — 13 разделов + указание источников (файлов)

3. **KPI и инсайты**:
   - Короткий вывод (3-4 тезиса)
   - KPI в цифрах: выручка, прибыль, маржа, ROAS, ДРР
   - Влияние себестоимости (до/после)
   - ТОП потерь (где теряются деньги)
   - Убыточные SKU

4. **Финансы** — детальная P&L таблица + комментарии по каждой статье + расчёт прямых потерь (4 категории) + рекомендации

5. **Воронка продаж** — визуальная воронка + таблица метрик + комментарии

6. **Реклама** — метрики + анализ эффективности + выявление связок без заказов

7. **Остатки** — KPI остатков, дни покрытия, порог, риск дефицита, SKU с зависшими остатками

8. **Ассортимент / SKU**:
   - TOP вклад в прибыль
   - ABC-анализ (A/B/C по прибыли)
   - SKU по категориям ABC
   - ABC + остатки + реклама (перекрёстный анализ)
   - SKU с остатками и слабым движением
   - SKU с низкой маржинальностью
   - Эффективность товаров (таблица)

9. **ТОП-5 SKU** — глубокий разбор каждого:
   - Остаток, выручка, прибыль, заказы, выкупы, средняя цена
   - Прибыль на заказ, маржа, ROI
   - Логистика: факт vs расчётная vs нормальная
   - Переплата
   - Реклама: расход на заказ, ДРР, интерпретация, нагрузка
   - Риск: НИЗКИЙ/ВЫСОКИЙ
   - Вывод и рекомендация

10. **Локальные заказы и размещение** — распределение по регионам, рекомендации по локальному размещению

11. **Логистика** — региональные риски, SKU в зоне риска, чувствительность, выводы

12. **Переплата за логистику** — модель расчёта, SKU с риском удорожания

13. **Потери из-за плохой локализации** — модельная оценка, TOP-10 не-локальных заказов

14. **Поисковые запросы**:
    - Всего запросов, с рекламой, убыточные, слабые, эффективные
    - Потери на убыточных
    - TOP-10 убыточных/слабых/эффективных запросов
    - Гипотезы роста (запросы с высоким CTR без рекламы)

15. **План действий / рекомендации** — приоритизированная таблица (P0/P1), блок, действие, ожидаемый эффект + 7 пунктов итогового "что делать"

16. **Приложение** — диагностика входных данных (какие файлы использованы, что пропущено)

### 4.3. Что делают ВЫ лучше конкурентов (сильные стороны ваших отчётов)

| Ваша сильная сторона | Почему это важно |
|---------------------|----------------|
| **Глубокий недельный аудит с инсайтами** | Большинство сервисов дают сырые данные, но не формируют структурированный аудит с выводами и планом действий. Ваш аудит — это "отчёт консультанта", а не "дашборд аналитика" |
| **Региональная аналитика и локализация** | Мало кто из конкурентов считает потери от плохой локализации и даёт рекомендации по размещению на уровне SKU→регион. Это сильное конкурентное преимущество для FBO |
| **Перекрёстный ABC + остатки + реклама** | В одном блоке показано, как ABC-категория пересекается с наличием остатков и рекламной активностью. Это операционное золото |
| **Детальный разбор ТОП-5 SKU с логистикой и рисками** | Конкуренты показывают таблицу, но не дают текстовый вывод с рекомендацией по каждому SKU |
| **Анализ поисковых запросов с гипотезами роста** | Найти запросы с высоким CTR без рекламы — это фича уровня Anabar, но в вашем аудите она бесплатная и понятная |
| **Приоритизированный план действий (P0/P1)** | Превращение аналитики в todo-лист для владельца бизнеса. Мало кто так делает |
| **Диагностика входных данных** | Прозрачность: пользователь видит, из каких файлов собран отчёт и что не хватает. Это повышает доверие |

### 4.4. Слабые стороны ваших отчётов (где отстаётё от конкурентов)

| Слабая сторона | Что делают конкуренты | Последствия |
|---------------|----------------------|-------------|
| **Ежедневный отчёт — просто "срез данных"** | Конкуренты дают алерты, тренды, сравнения, рекомендации | Пользователь теряет время на интерпретацию |
| **Нет цветовой индикации** | Pi-Data, MPfact — красный/жёлтый/зелёный на проблемных зонах | Проблемы не бросаются в глаза |
| **Нет сравнения с предыдущими периодами** | Все конкуренты показывают динамику (вчера/неделю/месяц назад) | Невозможно понять, улучшается ли ситуация |
| **Нет нормализации и прогноза** | Аудит нормализует потери в месяц/год, но ежедневный — нет | Ежедневный отчёт не даёт перспективы |
| **Нет интеграции с 1С/МойСклад** | MPfact, МойСклад, Pi-Data | Ручной ввод себестоимости, ошибки |
| **Нет командного доступа** | MPfinassist, Pi-Data — роли и права | Нельзя делегировать просмотр менеджеру |
| **Нет внешних расходов** | MPfact, Pi-Data — можно добавить произвольные расходы | P&L неполный |
| **Реклама в ежедневном отчёте — только сырые метрики** | Anabar — автокорректировка ставок, рекомендации | Пользователь не знает, что с этим делать |
| **Нет прогноза остатков / дефицита** | Pi-Data — план поставок с расчётом | Риск упустить продажи или переплатить за хранение |
| **Ежедневный отчёт не привязан к недельному** | Два отчёта живут отдельной жизнью | Пользователь не видит, как дневные действия влияют на недельный результат |

## 5. SWOT-анализ вашей системы отчётов

### Strengths (Сильные стороны)
1. **Уникальная глубина недельного аудита** — структурированный консультантский подход, а не просто дашборд
2. **Региональная аналитика и локализация** — редкая фича на рынке
3. **Перекрёстный ABC-анализ** — соединение прибыли, остатков и рекламы
4. **Поисковые гипотезы роста** — обнаружение спроса без рекламы
5. **Приоритизированный план действий** — превращение данных в работу
6. **Прозрачность расчётов** — диагностика входных данных
7. **Два источника данных** (API + файлы) — резервирование и проверка

### Weaknesses (Слабые стороны)
1. **Ежедневный отчёт — просто срез, не инструмент управления**
2. **Разрыв между ежедневным и недельным** — нет связи, нет перетекания инсайтов
3. **Нет визуальных сигналов** — цвета, тренды, стрелки роста/падения
4. **Нет динамики** — сравнение с предыдущими днями
5. **Нет интеграции с учётными системами** — себестоимость вручную
6. **Нет командного функционала** — один пользователь, нет ролей
7. **Нет произвольных расходов** — полная P&L невозможна

### Opportunities (Возможности)
1. **Сделать ежедневный отчёт "мини-аудитом"** — внедрить инсайты и рекомендации из недельного
2. **Ежедневные алерты + еженедельная глубина** — гибридная модель, которой нет у конкурентов
3. **Автоматизация рекламных рекомендаций** — отключить/усилить/тестировать на основе дневных данных
4. **Прогноз остатков и дефицита** — ежедневный расчёт дней покрытия с алертом
5. **Телеграм-бот / email с пушами** — конкуренты делают отчёты, вы можете делать пуш-уведомления
6. **Интеграция с МойСклад** — стандарт рынка, ускорит внедрение

### Threats (Угрозы)
1. **WB усложняет API и ограничивает данные** — риск для API-отчёта
2. **Конкуренты добавляют AI** — Anabar уже автоматизирует ставки, нужно догонять
3. **Падение цен на рынке** — MPfinassist от 690 ₽/мес, барьер входа низкий
4. **Пользователи устают от email-отчётов** — нужно интерактивное взаимодействие

## 6. Рекомендации: что внедрить из недельного аудита в ежедневный отчёт

### 6.1. Минимум (быстрый win, 1-2 дня работы)

#### A. Добавить блок "Сводка и действия" на 1-й экран
Сделайте его главным, а не таблицей. Пример:

```
┌──────────────────────────────────────────┐
│  СВОДКА НА 25.06.2026                    │
│                                          │
│  ⚠️  Возвраты: 2 шт (норма: 0)           │
│  🔥  Реклама: -178 ₽ без заказов         │
│  📦  Остатки: 159 шт (31 день) — норма   │
│  💰  Маржа: 36.7% (вчера: 41.2% ↓)       │
│                                          │
│  Что делать сегодня:                     │
│  1. Проверить причину возвратов          │
│  2. Поставить на паузу рекламные связки  │
│     без заказов (3 запроса)              │
│  3. Проверить остатки ТОП-1 SKU (0 шт)   │
└──────────────────────────────────────────┘
```

#### B. Добавить сравнение с предыдущим днём и недельной средней
Каждую метрику показывать с дельтой:
- Маржа 36.7% (вчера 41.2% ↓4.5 п.п.) (неделя 38.1%)
- Заказы 3 шт (вчера 5 ↓40%)
- Выкупы 5 шт (вчера 7 ↓28%)

#### C. Добавить цветовую индикацию проблем
- 🔴 Красный: возвраты выше нормы, реклама без заказов, остатки = 0 у A-SKU
- 🟡 Жёлтый: маржа ниже 30%, CTR рекламы < 3%, запасы > 60 дней
- 🟢 Зелёный: всё в норме

### 6.2. Средний уровень (1-2 недели работы)

#### D. Добавить "Потери дня"
Рассчитывать ежедневно:
- Реклама без заказов (₽)
- Убыточные SKU (если есть)
- Зависшие остатки (оценка)
- Переплата логистики (если данные есть)

Итого: "Сегодня потеряно X ₽" + "Недельный тренд: X ₽/день"

#### E. Добавить ABC-флаг к ТОП-SKU
Вместо просто "ТОП-1, ТОП-2, ТОП-3" добавить:
- Категория: A (81% прибыли) / B (15%) / C (4%)
- Риск: дефицит / избыток / норма
- Рекомендация: пополнить / сократить рекламу / усилить

#### F. Добавить блок "Реклама: что делать"
Вместо таблицы метрик — текстовые выводы:
- "3 запроса с расходом, но без заказов → потеря 178 ₽"
- "CTR 15.7% — отлично, но ROAS 0 → проверьте атрибуцию"
- "Рекомендация: отключить запросы X, Y, Z"

#### G. Добавить блок "Остатки: риски"
- SKU с 0 остатком и заказами вчера (риск дефицита)
- SKU с остатком > 90 дней (риск заморозки)
- Дни покрытия по кабинету (как в аудите: 27.11 дней)

#### H. Добавить "Недельный тренд" (скользящие 7 дней)
- Средняя маржа за 7 дней: X%
- Средние заказы за 7 дней: X шт
- Тренд: ↓ / → / ↑

### 6.3. Максимум (1-2 месяца работы)

#### I. Добавить поисковые алерты (ежедневно)
- Новые запросы с CTR > 15% без рекламы → "Гипотеза роста: тестировать"
- Запросы с расходом > 100 ₽ и 0 заказов за 3 дня → "Отключить"
- Запросы с ДРР > 25% → "Снизить ставки"

#### J. Добавить региональные алерты (ежедневно)
- Если > 50% заказов региона идёт не-локально → алерт
- Рекомендация: рассмотреть поставку в регион X

#### K. Связать ежедневный и недельный отчёты
- В ежедневном отчёте добавить: "По плану недельного аудита: сегодня нужно сделать X"
- В недельном аудите: "Отслеживайте в ежедневном отчёте: Y"

#### L. Добавить прогноз
- "При такой марже и расходах к концу месяца прибыль: X ₽"
- "Если не отключить убыточную рекламу, потери за месяц: Y ₽"

#### M. Сделать интерактивные элементы
- Кнопка "Я сделал это" на рекомендациях
- Отслеживание выполнения плана из недельного аудита
- Напоминания: "3 дня назад рекомендовали отключить запрос X — статус?"

## 7. Идеальная структура ежедневного отчёта (рекомендуемая)

```
Страница 1: Экран управления (1 страница)
├── Шапка: кабинет, дата, период сравнения
├── Светофор: 3-4 ключевых алерта (🔴🟡🟢)
├── KPI с дельтами (вчера / 7-дн ср. / недельный план)
├── Потери дня (₽ и источники)
├── Что делать сегодня (3-5 приоритетных действий)
└── Быстрые ссылки: ТОП-SKU | Реклама | Остатки | Поиск

Страница 2: Финансы и воронка (1 страница)
├── Заказы/выкупы с динамикой
├── P&L дня с дельтами
├── Воронка с конверсиями + динамика
└── Ключевые метрики недели (скользящие)
```
