# Security notes (multi-cabinet)

Этот репозиторий содержит скелет для работы с несколькими кабинетами (cabinets/*).

## Что НЕ хранить в репозитории
- API токены WB
- SMTP пароли
- ключи LLM
- любые выгрузки/сырые отчёты продавцов

Они должны находиться:
- либо в GitHub Secrets (для Actions)
- либо в `cabinets/<seller>/secrets.env` локально (и этот файл игнорируется git)

## Изоляция данных между кабинетами
- каждый кабинет имеет собственную папку `cabinets/<seller>/...`
- пайплайн v3 пишет артефакты только в папку текущего `seller_id`
- при запуске по всем кабинетам, обработка идёт последовательно, контекст не переиспользуется

## Рекомендации для прод-версии
- шифрование секретов и сырых данных (например age/sops, KMS)
- отдельный storage backend (S3/minio) с namespace per seller
- аудит доступа (логирование кто/когда запускал пайплайны)
