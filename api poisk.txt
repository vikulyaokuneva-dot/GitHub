Понял, кабинет действующий, лимиты WB API — больная тема. Смотрю на твой отчёт глазами клиента, который сравнивает с конкурентами.

**Что делают лидеры рынка (MPStats, SelSup, Маяк, Data Insight) лучше:**

1. **Сравнение периодов** — у тебя «11 заказов», у них «11 заказов, +37% к вчера, -12% к неделе назад, тренд ↗». Твой отчёт статичен, их — динамичен. Клиент за 3 секунды понимает, растёт он или падает.

2. **Визуализация трендов** — мини-графики за 7/14/30 дней прямо в отчёте. У тебя таблицы, у них sparklines. На телефоне график понятнее цифр.

3. **Приоритизация алертов** — у тебя 4 SKU разбросаны по 3 блокам (риск, внимание, алерты). У конкурентов — «Топ-3 проблемы сегодня» с цветом и действием. Селлер не хочет читать 4 таблицы, он хочет знать: что сделать прямо сейчас.

4. **Unit-экономика по товару** — у тебя «прибыль -192,74 ₽» без разбивки. У нормальных сервисов: себестоимость, логистика, комиссия, реклама, налог, чистая маржа. Твой отчёт говорит «ты в минусе», но не говорит «где утечка».

5. **Конкуренты и цены** — ни одного сервиса оцифровки без этого. Средняя цена по категории, твоя позиция, динамика цен. У тебя нет.

6. **Рекламные аукционы** — ставки конкурентов, перекрёстный анализ, рекомендации по ставкам. У тебя «CPC 2,97 ₽» без контекста: дорого это или дёшево?

7. **Поставки и остатки** — прогноз дефицита, норма запаса, рекомендация когда везти. У тебя «131 шт» — это на 3 дня или на 3 месяца?

**Что у тебя лучше, чем у конкурентов (можно развить):**

- Компактность. MPStats — перегружен, твой отчёт можно прочитать за 2 минуты.
- Прямые рекомендации («Снижение цены/распродажа остатков»). У многих только данные, без action items.
- Ежедневная частота. Многие делают недельные, а селлеру нужен ежедневный пульс.

**Что убрать/переделать в твоём отчёте:**

| Блок | Что сделать |
|------|-------------|
| Финансы (unavailable) | Убрать полностью или заменить на «Финансовый отчёт WB: данные за 21.06 появятся 23.06» |
| Прибыль по товарам | Убрать дубли «топ прибыльных / убыточные». Оставить одну таблицу с маржой, только если данные есть |
| ABC-анализ | Не показывать, если все SKU = C. Или показывать с пояснением «Недостаточно данных для ABC» |
| SKU health | Сжать до одного блока «Проблемные SKU» с рейтингом по критичности |
| Рекомендации по рекламе | Перевести на русский, сделать конкретными под цифры клиента |

**Идеальная структура ежедневного отчёта (сверху вниз):**

1. **Дашборд за 10 секунд** — 4-5 цифр с динамикой: заказы, выручка, прибыль, рекламный расход, остатки. Зелёный/красный цвет.
2. **Что требует действия сегодня** — 1-3 алерта с кнопкой/ссылкой.
3. **Воронка** — мини-график + коэффициенты.
4. **Реклама** — расход, заказы, эффективность + рекомендация.
5. **SKU — фокус недели** — 1-2 товара, которые двигают метрики.
6. **Оперативный срез** — live-данные для контекста.
