## Главные выводы

### 1. Показы за день по кабинету — есть

**Через Analytics API:**
```http
GET /openapi/analytics?nmIds=...&period=start=2026-06-25;end=2026-06-25
```
→ `openCount` = все показы карточки (органика + реклама)

**Через Promotion API:**
```http
GET /api/v1/promotion/adverts
```
→ Внутри `days[].views` = только рекламные показы (суммируете по кампаниям за дату)

### 2. Показы за день по SKU — тоже есть

**Через Promotion API:**
- Внутри `days[].apps[].nms[]` → `nmId` (SKU) + `views` (показы) + `clicks` + `orders` + `sum` (расход)
- Суммируете по всем кампаниям для конкретного `nmId` за день

**Через Analytics API:**
- `products[].statistic.selected.openCount` = все показы по конкретному SKU

### 3. Поисковые запросы за день — НЕТ

WB API **не отдаёт** поисковые запросы в дневном разрезе. Только:
- Скаченные отчёты из кабинета (недельные)
- Внутренние API кабинета (требуют парсинга браузера)

**Вывод:** в ежедневном отчёте блок «Поисковые запросы» — **убрать или заменить** на «Рекламные кампании» с данными из Promotion API.

### 4. Структура данных в Promotion API (главное)

```json
{
  "advertId": 123,
  "days": [
    {
      "date": "2026-06-25T00:00:00Z",
      "views": 784,      // ← показы за день
      "clicks": 75,      // ← клики за день
      "orders": 0,       // ← заказы за день
      "sum": 378.49,     // ← расход за день
      "sum_price": 0,    // ← выручка за день
      "apps": [
        {
          "nms": [
            {
              "nmId": 221725278,  // ← SKU
              "views": 21,        // ← показы по SKU
              "clicks": 1,
              "orders": 0,
              "sum": 10.19
            }
          ]
        }
      ]
    }
  ]
}
```

### 5. Что делать завтра

1. **Тестовый запрос:** `GET /api/v1/promotion/adverts` → проверьте, есть ли в ответе `days` с датами.
2. **Если есть:** фильтруете `days` по дате, суммируете `views`, `clicks`, `orders`, `sum` по всем кампаниям.
3. **Для SKU:** суммируете по `nmId` внутри `days[].apps[].nms[]`.
4. **Сверка:** сумма `sum` по рекламе за день должна совпадать с «Расход на рекламу» в вашем отчёте (±5%).
5. **В ежедневном отчёте** вместо «Поисковые запросы» делаете блок «Рекламные кампании» (или «Реклама по SKU») с данными из Promotion API.
